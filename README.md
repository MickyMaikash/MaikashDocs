# MaikashDocs

> **What I learn. I write it down.**

MaikashDocs is my personal documentation site — a place where I keep the programming concepts, code, notes, and things I discover while learning and building projects.

I don't want the things I learn to disappear after I finish a project. So I keep them here — simple, searchable, and easy to revisit.

## What you'll find here

* 📚 Programming concepts and notes
* 💻 Code examples
* 🧠 Things I discover while learning
* 🛠️ Notes from building projects
* ✍️ Coding practice and experiments
* 🔄 Things I want to revisit later

## The idea

**Learn something.**
**Write it down.**
**Build with it.**
**Come back when you forget.**

This isn't meant to be a perfect reference or a complete guide to everything.

It's my own collection of things I've learned along the way.

## Why MaikashDocs?

I learn better when I write things down and come back to them later.

Instead of letting useful knowledge get scattered across tutorials, projects, bookmarks, and random files, I keep it organized here so I can quickly find it whenever I need it.

---

**Built for learning. Built for revisiting.**
