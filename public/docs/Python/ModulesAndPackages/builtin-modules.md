# Python Built-in Modules

This page lists useful Python built-in modules for learning and quick reference.

## 1. os
- Interact with the operating system.
- Common functions: `os.getcwd()`, `os.listdir()`, `os.path.join()`, `os.path.exists()`.
- Useful for working with files, directories, and environment variables.

## 2. sys
- Access Python runtime environment.
- Common functions: `sys.argv`, `sys.exit()`, `sys.path`, `sys.version`.
- Useful for command-line scripts and module import troubleshooting.

## 3. math
- Provides mathematical functions.
- Common functions: `math.sqrt()`, `math.ceil()`, `math.floor()`, `math.sin()`, `math.pi`.
- Useful for numeric calculations and algorithm learning.

## 4. random
- Generate random numbers and choices.
- Common functions: `random.random()`, `random.randint()`, `random.choice()`, `random.shuffle()`.
- Useful for simulations, games, and testing.

## 5. datetime
- Work with dates and times.
- Common classes: `datetime.date`, `datetime.time`, `datetime.datetime`, `datetime.timedelta`.
- Useful for scheduling, timestamps, and date calculations.

## 6. json
- Read and write JSON data.
- Common functions: `json.loads()`, `json.dumps()`, `json.load()`, `json.dump()`.
- Useful for APIs, configuration files, and data exchange.

## 7. collections
- High-performance container datatypes.
- Common classes: `Counter`, `defaultdict`, `OrderedDict`, `deque`, `namedtuple`.
- Useful for handling grouped data and improving code clarity.

## 8. itertools
- Functions for efficient looping and combinatorics.
- Common functions: `itertools.chain()`, `itertools.combinations()`, `itertools.permutations()`, `itertools.groupby()`.
- Useful for generating sequences and working with iterators.

## 9. functools
- Higher-order functions for functional programming.
- Common functions: `functools.partial()`, `functools.reduce()`, `functools.lru_cache()`.
- Useful for decorators, caching, and function tools.

## 10. pprint
- Pretty-print Python objects.
- Common function: `pprint.pprint()`.
- Useful for debugging nested structures and readable output.

## Quick learning tips
- Start with small examples for each module.
- Read the official Python documentation for details and parameters.
- Practice by writing short scripts that use one or two modules together.
- Use `help(module)` in Python to see available functions and classes.
