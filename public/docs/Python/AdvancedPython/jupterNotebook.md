# Jupyter Notebook ShortCut keys
| Shortcut        | Action                       |
| --------------- | ---------------------------- |
| `Shift + Enter` | Run cell & move to next cell |
| `Ctrl + Enter`  | Run cell & stay on same cell |
| `Alt + Enter`   | Run cell & create a new cell |
| `Esc`           | Enter command mode           |
| `Enter`         | Edit selected cell           |
| `A`             | Add cell **above**           |
| `B`             | Add cell **below**           |
| `D`, `D`        | Delete selected cell         |
| `M`             | Change cell to **Markdown**  |
| `Y`             | Change cell to **Code**      |
| `C`             | Copy cell                    |
| `V`             | Paste cell below             |
| `X`             | Cut cell                     |
| `Z`             | Undo deleted cell            |
| `Shift + M`     | Merge selected cells         |
| `Ctrl + S`      | Save notebook                |
| `I`, `I`        | Interrupt running code       |
| `0`, `0`        | Restart kernel               |
