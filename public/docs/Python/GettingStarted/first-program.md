# First Python Program

After installing Python, let's create and run our first Python program.

## Creating a Python File

Create a file named:

```
main.py
```

Python files always use the `.py` extension.

## Writing Your First Program

Add the following code:

```python
print("Hello, World!")
```

## Output

```
Hello, World!
```

The `print()` function displays information on the screen.

## Understanding the Code

Example:

```python
print("Hello, World!")
```

### print()

`print()` is a built-in Python function used to display output.

### Text Inside Quotes

The text:

```python
"Hello, World!"
```

is called a string.

## Printing Multiple Values

You can print multiple values:

```python
name = "Alex"
age = 20

print(name)
print(age)
```

Output:

```
Alex
20
```

## Printing Variables

Variables store data that can be reused.

Example:

```python
name = "Python"

print("I am learning", name)
```

Output:

```
I am learning Python
```

## Taking User Input

Python can take input from users.

Example:

```python
name = input("Enter your name: ")

print("Hello", name)
```

Output:

```
Enter your name: Alex
Hello Alex
```

## Python Comments

Comments are used to explain code.

Example:

```python
# This is my first Python program

print("Hello Python")
```

Python ignores comments while executing the program.

## Common Beginner Mistakes

### Missing Quotes

Incorrect:

```python
print(Hello)
```

Correct:

```python
print("Hello")
```

### Wrong File Extension

Incorrect:

```
main.txt
```

Correct:

```
main.py
```

### Incorrect Indentation

Python uses indentation to define blocks of code.

Example:

```python
if True:
    print("Python")
```

## Summary

The `print()` function is the first step in learning Python. By writing simple programs, you can gradually understand Python syntax and programming concepts.
