# Setting Up VS Code for Python

Visual Studio Code (VS Code) is one of the most popular code editors for Python development.

It provides features like:

- Code suggestions
- Debugging
- Extensions
- Terminal integration
- Syntax highlighting

## Installing VS Code

Download VS Code from the official website:

https://code.visualstudio.com/

Install it using the default settings.

## Installing Python Extension

After installing VS Code:

1. Open VS Code.
2. Go to the Extensions panel.
3. Search for:

```
Python
```

4. Install the extension provided by Microsoft.

The Python extension provides:

- Python syntax support
- Code completion
- Debugging tools
- Running Python files

## Creating a Python Project

Create a new folder for your project.

Example:

```
PythonProjects
```

Open the folder in VS Code.

Go to:

```
File → Open Folder
```

Select your project folder.

## Creating Your First Python File

Create a new file:

```
main.py
```

Python files use the `.py` extension.

Example:

```
main.py
```

## Selecting Python Interpreter

The interpreter is the program that runs your Python code.

To select it:

1. Press:

```
Ctrl + Shift + P
```

2. Search:

```
Python: Select Interpreter
```

3. Choose your installed Python version.

Example:

```
Python 3.12
```

## Running Python Code

You can run Python programs in two ways.

## Method 1: Using Run Button

Click:

```
Run ▶
```

in the top-right corner.

## Method 2: Using Terminal

Open the VS Code terminal:

```
Terminal → New Terminal
```

Run:

```bash
python main.py
```

Enable:

- Auto Save
- Format on Save

## Summary

VS Code provides a complete development environment for writing, testing, and debugging Python programs efficiently.
