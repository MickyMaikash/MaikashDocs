# Installing Python

Before writing Python programs, you need to install Python on your computer.

Python is available for Windows, macOS, and Linux.

## Download Python

Download Python from the official website:

https://www.python.org/

Download the latest stable version.

## Installing Python on Windows

Follow these steps:

1. Open the Python installer.
2. Select the option:

```
Add Python to PATH
```

3. Click:

```
Install Now
```

4. Wait for the installation to complete.

## Verify Python Installation

Open Command Prompt or Terminal.

Run:

```bash
python --version
```

Example output:

```
Python 3.12.0
```

If you see the Python version, installation was successful.

## Running Python

Open the Python interactive shell:

```bash
python
```

Example:

```python
>>> print("Hello Python")
Hello Python
```

To exit:

```python
exit()
```

## Installing Python on macOS

Using Homebrew:

```bash
brew install python
```

Check installation:

```bash
python3 --version
```

## Installing Python on Linux

Most Linux distributions come with Python pre-installed.

Check version:

```bash
python3 --version
```

Install Python if required:

```bash
sudo apt install python3
```

## Common Installation Issues

### Python is not recognized

Solution:

- Reinstall Python.
- Make sure "Add Python to PATH" is selected.

### Multiple Python Versions

Check available versions:

```bash
py --list
```

## Summary

After installing Python successfully, you can start writing and running Python programs.
